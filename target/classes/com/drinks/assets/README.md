# Assets Directory

Place the following files here (copy from React `public/`):

- `logo.png` — Kamnyweso logo (used in PortalSelector)
- `tusker.png` — Tusker Lager product image
- `guinness.png` — Guinness product image
- `coca-cola.png` — Coca Cola product image
- `fanta.png` — Fanta Orange product image
- `white-cap.png` — White Cap product image
- `stoney.png` — Stoney Ginger product image
- `johnnie-walker.png` — Johnnie Walker product image
- `smirnoff.png` — Smirnoff Vodka product image
- `bells.png` — Bell's Whisky product image
- `tusker-cider.png` — Tusker Cider product image

Images are referenced as `/tusker.png`, `/guinness.png` etc. in the mock data.
When running the app, ensure these files are in the resources root or update paths in `MockDataService.java`.
